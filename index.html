Le projet présenté

Description courte : Robot autonome capable d'identifier, saisir et déplacer des cibles selon le thème de l'année. Architecture logicielle : contrôleur C++, capteurs vision et distance, logique de décision embarquée.

  • Langages : C/C++, Python
  • Électronique : Microcontrôleur STM32, driver moteurs, capteurs lidar/ultrason
  • Outils : Git, simulation légère, tests unitaires
